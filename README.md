# Martas-a11y

Building **[TelecomDesk UAE](https://telecomdeskuae.com/)** - a du & e& (Etisalat) consumer
guide for UAE residents: plan comparisons, balance and coverage fix-guides, contract cost
calculators, and a free NOC letter generator. Every figure is checked against operator
published pages before it goes live.

## Open tools and guides

- [NOC letter tool](https://telecomdeskuae.com/noc.html) - free NOC request generator
- [du & e& plans, compared](https://telecomdeskuae.com/plans.html) - with waiver vs promo maths
- [Business landline and internet guides](https://telecomdeskuae.com/business.html)
- [Fix guides](https://telecomdeskuae.com/guides.html) - step-by-step telecom fixes
- [Du balance check code, explained](https://telecomdeskuae.com/blog/du-balance-check-code-2.html)

All guides are written and verified by [Tasleem Akhtar](https://telecomdeskuae.com/) and updated
when operators change their published rates.
